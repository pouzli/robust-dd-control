# Устойчивость и робастность управления нелинейной динамической системы, идентифицированной на основе данных

Репозиторий содержит минимально рабочий, но полный pipeline для дипломной темы по **data-driven идентификации** нелинейной системы и **анализу робастной устойчивости** с/без обратной связи.

## Краткая постановка
Рассматривается неизвестная система
$$
\dot x = f(x) + Bu,
$$
где в начальной части анализируется автономный случай $u=0$. Предполагается, что доступны выборки $(x(t_k), \dot x(t_k))$. Неизвестное векторное поле аппроксимируется моделью
$$
\hat f(x)=\Theta(x)C,
$$
где $\Theta(x)$ — полиномиальный словарь базисных функций, а $C$ — матрица коэффициентов (least squares / ridge). Затем рассчитываются residuals
$$
r^{(k)} = \dot x(t_k)-\hat f(x(t_k)),
$$
по ним оценивается детерминированная неопределенность $\varepsilon$ как высокий квантиль $\|r^{(k)}\|$. На основании $\hat f$ строится Якобиан в равновесии, решается уравнение Ляпунова и численно проверяется робастная устойчивость для возмущенной динамики при $\|\Delta\|\le\varepsilon$. После этого добавляется линейная обратная связь $u=Kx$ и проводится сравнение вариантов стабилизации.

## Основной тестовый пример
Используется нелинейная система с перекрестными членами:
$$
\dot x_1 = -x_1 + x_2 + \gamma x_1x_2, \qquad
\dot x_2 = -2x_2 + \delta x_1^2,
$$
с параметрами $\gamma=0.8,\,\delta=0.6$.

## Структура проекта
```text
.
├── data/                  # raw/ и processed/ данные
├── notebooks/             # 4 последовательных ноутбука pipeline
├── src/                   # модульный код (идентификация, Lyapunov, control...)
├── results/               # figures/, tables/, metrics/
├── report/                # промежуточный отчет
└── tests/                 # базовые unit tests
```

## Установка и запуск
```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

Запуск тестов:
```bash
pytest
```

Запуск ноутбуков (по порядку):
1. `notebooks/01_generate_data.ipynb`
2. `notebooks/02_identification.ipynb`
3. `notebooks/03_robust_stability.ipynb`
4. `notebooks/04_feedback_control.ipynb`

Все результаты сохраняются в `results/`, а dataset — в `data/processed/`.

## Описание ноутбуков
- **01_generate_data**: генерация траекторий, сбор \((x, \dot x)\), сохранение датасета и базовых фазовых графиков.
- **02_identification**: выбор базиса, оценка \(C\), сравнение true/identified динамики, анализ residuals, оценка \(\varepsilon\).
- **03_robust_stability**: Якобиан в нуле, уравнение Ляпунова, уровень-функции \(V(x)\), моделирование при ограниченном возмущении.
- **04_feedback_control**: добавление \(B\), набор матриц \(K\), анализ замкнутой системы и сравнение с uncontrolled случаем.

## Основные результаты текущего этапа
- Реализована рабочая data-driven идентификация через полиномиальный словарь.
- Реализована оценка \(\varepsilon\) по квантили норм residuals.
- Реализован Lyapunov-based анализ (\(A, P, V(x)\)) для open-loop и closed-loop.
- Реализовано численное моделирование при ограниченной неопределенности.
- Подготовлен промежуточный технический отчет с интерпретацией графиков.

## Что можно расширять следующим шагом
1. Более строгая локальная область \(\Omega\) (не только bounding box).
2. Альтернативные словари \(\Theta(x)\) (например, sparse или piecewise).
3. Сравнение методов синтеза \(K\) (LQR/H∞-подходы).
4. Переход к более размерным нелинейным системам и анализу инвариантных множеств.
