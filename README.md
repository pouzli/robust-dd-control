# Устойчивость и робастность управления нелинейной динамической системы, идентифицированной на основе данных

Репозиторий содержит материалы к дипломной работе по **data-driven идентификации** нелинейных систем, **оценке неопределённости** и **анализу робастной устойчивости** с линейной обратной связью.

## Основной результат

Текущий главный воспроизводимый артефакт:

- `notebooks/05_all_examples_pipeline.ipynb`

Этот ноутбук запускает полный pipeline для пяти тестовых систем и трёх словарей признаков:

- генерирует или подготавливает данные;
- идентифицирует модель;
- оценивает неопределённость `ε` по residuals;
- проверяет локальную устойчивость;
- сравнивает open-loop и closed-loop динамику;
- сохраняет итоговые таблицы, метрики и фигуры.

Основные результаты этого ноутбука вынесены в отдельную папку:

- `results/main_pipeline/datasets/`
- `results/main_pipeline/figures/`
- `results/main_pipeline/tables/`
- `results/main_pipeline/metrics/`

## Краткая постановка

Рассматривается система

```text
dx/dt = f(x) + B u,
```

где функция `f(x)` неизвестна и восстанавливается по данным `(x(t_k), dx/dt(t_k))`. Используется аппроксимация

```text
f_hat(x) = Theta(x) C,
```

где `Theta(x)` — словарь базисных функций, а `C` — матрица коэффициентов, определяемая методом наименьших квадратов. Затем по остаткам идентификации оценивается величина неопределённости `ε`, после чего проводится Lyapunov-based анализ устойчивости и сравнивается поведение системы без управления и с обратной связью `u = Kx`.

## Тестовые системы

В основном ноутбуке сравниваются пять эталонных систем из `src/systems.py`:

- `linear_damped`
- `quadratic_oscillator`
- `van_der_pol`
- `cross_coupled`
- `saturated`

## Установка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

## Запуск

Основной сценарий:

```bash
jupyter notebook notebooks/05_all_examples_pipeline.ipynb
```

Альтернативный пакетный запуск:

```bash
python scripts/run_all_examples.py
```

Тесты:

```bash
pytest
```
